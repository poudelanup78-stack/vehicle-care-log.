# Vehicle Care Log

A Flutter-based mobile and web app that helps bike and car owners track
service history, fuel usage and document expiry dates, with reminders so
maintenance and renewals are never missed.

## Planned Features
- User authentication
- Add vehicle (bike/car, number, model)
- Service history and next service reminder
- Fuel log
- Document expiry alerts (bluebook, insurance)
- Monthly cost summary

## Tech Stack
Flutter (Dart), Firebase Authentication, Cloud Firestore, MVVM architecture
